EDI Comparator — Cloudflare Pages

IMPORTANT: index.html is at the repository ROOT.

GitHub repository structure:
  index.html
  README.md

For your existing edi-comparision.pages.dev Cloudflare Pages project:
- Framework preset: None
- Build command: leave empty
- Build output directory: .
- Root directory: /
- Production branch: main

Upload index.html and README.md to the top level of your GitHub repository (not inside a subfolder).
Commit to main, then wait for the Pages deployment to finish.

The app compares files in the browser; it does not upload the selected EDI file contents to your site.
